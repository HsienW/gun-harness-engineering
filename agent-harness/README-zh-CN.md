# Agent Harness

[English](./README.md) | [繁體中文](./README-zh-TW.md) | [简体中文](./README-zh-CN.md)

本区整理 Agent 的行为控制：用户输入如何进入系统、模型能看见哪些内容、可使用哪些能力、行动前如何取得授权，以及用户如何在执行中介入。

## 阅读顺序

1. [Foundations](./foundations/README-zh-CN.md)：从定义、控制层与 Harness／Runtime 边界，读到设计原则及一次任务的完整流程。
2. [Input and Context](./input-and-context/README-zh-CN.md)：输入规范化、Context 组装、信任边界、Memory 与案例。
3. [Behavior and Capabilities](./behavior-and-capabilities/README-zh-CN.md)：行为指令、能力组装、能力选择与使用。
4. [Action Governance](./action-governance/README-zh-CN.md)：工具风险、授权、人工确认、受控派送与副作用处理。
5. [Interaction and Feedback](./interaction-and-feedback/README-zh-CN.md)：执行中新输入、Run 归属、澄清与恢复、取消与修正及反馈评估。
