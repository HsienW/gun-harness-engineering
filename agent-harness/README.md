# Agent Harness

[English](./README.md) | [繁體中文](./README-zh-TW.md)

This section covers how an agent's behavior is controlled: how user input enters the system, what the model can see, which capabilities it can use, how authorization is obtained before it acts, and how users can step in during execution.

## Reading Order

1. [Foundations](./foundations/README.md): Read from the definition, control surfaces, and Harness/Runtime boundary through design principles and one complete task walkthrough.
2. [Input and Context](./input-and-context/README.md): Input normalization, Context assembly, trust boundaries, Memory, and a case study.
3. [Behavior and Capabilities](./behavior-and-capabilities/README.md): Four articles covering instructions, capability composition, capability selection, and use.
4. [Action Governance](./action-governance/README.md): Six articles covering tool risk, authorization, human confirmation, governed dispatch, and side effects.
5. [Interaction and Feedback](./interaction-and-feedback/README.md): Six article drafts in English and Traditional Chinese covering in-flight input, Run ownership, clarification, cancellation, feedback evaluation, and a combined case.
